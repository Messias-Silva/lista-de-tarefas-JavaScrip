Lista de Tarefas & Gerenciador 📋

Um aplicativo web moderno, responsivo e intuitivo para gerenciamento de tarefas e organização diária, desenvolvido com HTML5, CSS3, JavaScript e jQuery.

🔗 Acesse o projeto online: messias-silva.github.io/lista-de-tarefas-J

🚀 Funcionalidades

Adição Dinâmica: Insira novas tarefas de forma rápida e simples.

Interface Responsiva: Layout otimizado tanto para computadores quanto para celulares e tablets (usando Flexbox, Grid e Media Queries).

Design Moderno: Estilização baseada em tons de azul com efeitos suaves e excelente contraste visual.

Remoção de Itens: Gerenciamento fácil para excluir tarefas concluídas.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica da página.

CSS3: Estilização avançada, gradientes, Flexbox e Grid Layout.

JavaScript (ES6+): Lógica de manipulação do DOM e eventos.

jQuery: Facilidade na manipulação de elementos e integração de scripts.

📂 Como executar o projeto localmente

Caso queira clonar e rodar o projeto na sua máquina:

Clone o repositório:

git clone https://github.com/messias-silva/lista-de-tarefas-J.git


Abra a pasta do projeto no seu editor de código favorito (como o VS Code).

Abra o arquivo index.html diretamente no seu navegador ou utilize uma extensão como o Live Server.
